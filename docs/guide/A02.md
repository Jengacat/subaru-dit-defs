# A02. Logger parameter reference

Every parameter in the stock (FA20DIT_Logger.xml) and patched (FA20DIT_Logger_LogPatch.xml) logger definitions, for
reading the numbers or building your own logger. *read* = conversion read in code; *inferred* = my interpretation.

## A02.1 Stock parameters (every 2015-2018 image)

| ID | Name | Conversion (SSM value x) | Conf | Notes |
|---|---|---|---|---|
| J01 | Engine Speed | rpm = x / 4 | read | |
| J02 | Coolant Temperature | °C = x − 40 (°F shown) | read | |
| J03 | Intake Air Temperature | °C = x − 40 (°F shown) | read | IAT 1 |
| J04 | Ignition Timing | ° = (x − 128) / 2 | read | Fired timing, full resolution |
| J05 | Mass Airflow | g/s = x / 100 | read | Clipped at 300 g/s |
| J06 | MAF Sensor Voltage | V = x × 0.02 | inferred | 5 V reference assumed |
| J07 | Manifold Absolute Pressure | kPa = x (psia shown) | inferred | One byte: max 255 kPa abs |
| J08 | Manifold Relative Pressure | kPa = x − 128 (psi shown) | read | Relative to *measured* baro |
| J09 | Barometric Pressure | kPa = x (psia shown) | read | |
| J10 | Wastegate Duty | % = x × 100 / 255 | read | 8-bit copy |
| J11 | Commanded Throttle | % = x × 100 / 255 | read | ECU throttle command |
| J12 | Battery Voltage | V = x × 0.08 | inferred | |
| J13 | Vehicle Speed | km/h = x | inferred | From the VDC over CAN; 10 km/h if lost |
| J14 | Knock Learning (DAM) | x / 16 | inferred | 0 to 1 |
| J15 | Throttle Position | % = x × 0.4 | read | Actual blade |
| J16-J18 | Throttle Scale (internal tags) | % | inferred | Probably the second throttle signal; not decoded |
| J19 | Closed Loop Lambda | λ = x / 128 | read | Measured or target not decoded |
| J20 | Closed Loop Target | λ | read | Early stage; covers only λ 0.96-1.17 |
| J21 | Fuel Correction (internal tag) | % = (x − 128) / 1.28 | inferred | 128 = none |

| J24-J27 | AVCS internals | raw | read | Role not decoded |
| J28 | Long-Term Fuel Trim | % = (x − 128) × 100 / 128 | read | 0.39 % per internal count |
| J29 / J30 | Intake Cam Advance Bank 1 / 2 | ° = x − 50 | inferred | Advance from rest |
| J31 / J32 | Exhaust Cam Retard Bank 1 / 2 | ° = x − 50 | inferred | Retard from rest |
| J33 | Accelerator Pedal | % = x × 100 / 256 | read | The pedal the torque request uses |
| J34 | ETC Motor Drive | x − 128 | inferred | Throttle motor effort |

## A02.2 Logging-patch parameters (patched ROMs only)

All 24 sit on the same SSM slots in every image. Two-slot parameters are 16-bit, high byte first. Slots 0x2D9-0x34F
are spare.

| ID | Slot(s) | Name | Conversion | Conf |
|---|---|---|---|---|
| L01 | 0x2B0/1 | Target Torque | Nm = x / 80 − 200; ft-lb = Nm × 0.7376 | read |
| L02 | 0x2B2/3 | Throttle Torque Request | same | read |
| L03 | 0x2B4 | Base Timing (selected map + IAT and coolant compensations, after the rate limit) | ° = signed x / 2 | read |
| L04 | 0x2B5 | Feedback Knock Correction | ° = signed x × 0.3516 | read |
| L05 | 0x2B6 | Fine Learning Knock Correction | ° = signed x × 0.3516 | read |
| L06 | 0x2B7 | Knock Correction Advance | ° = x × 0.3516 | read |
| L07 | 0x2B8 | Total Knock Correction (L04 + L05 + L06; not on the fired path) | ° = signed x × 0.3516 | read |
| L08 | 0x2B9 | Combustion Mode | 0-4 (4 = normal, 2 = stratified catalyst heating) | read |
| L09 | 0x2BA/B | Fuel Rail Pressure | MPa = x / 1639.34; psi = x × 0.08847 | read |
| L10 | 0x2BC/D | Target Fuel Rail Pressure | same | read |
| L11 | 0x2BE/F | Target Boost | kPa abs = (x + 3404) / 256; psi gauge = (kPa − 101.325) × 0.14504 | read |
| L12 | 0x2C0/1 | Boost Control Pressure | same | read |
| L13 | 0x2C2/3 | Wastegate Duty (Full Resolution) | % = x / 256 | read |
| L14 | 0x2C4/5 | Wastegate Duty Feedback | % = signed x / 256 | inferred unit |
| L15 | 0x2C6/7 | Closed Loop Target | λ = 32768 / x | read |
| L16 | 0x2C8/9 | A/F Correction (Closed Loop) | % = signed x / 327.68 | read |
| L17 | 0x2CA | A/F Learning | % = signed x × 0.3906 | inferred scale |
| L18 | 0x2CB/C | Throttle Model Air Requirement | % = x / 327.68 | inferred |
| L19 | 0x2CD/E | Torque Model Throttle Opening | % = x / 655.35 | inferred |
| L20 | 0x2CF/D0 | Throttle Required Area | raw (21468 = wide open) | read |
| L21 | 0x2D1/2 | ETC Target | % = (x − 10) / 460.09 | read |
| L22 | 0x2D3/4 | Intake Cam Target | ° = signed x × 180 / 65536 | inferred sign |
| L23 | 0x2D5/6 | Exhaust Cam Target | ° = signed x × 180 / 65536 | inferred sign |
| L24 | 0x2D7/8 | Injector Pulse Width (injector 1, first pulse) | ms = x × 0.0008 | inferred identity |

Notes: L11/L12 psi are relative to a fixed 101.325 kPa, not measured baro. L24 wraps above 52.4 ms, which only a
cranking pulse can reach. The logger's write command uses the same index table, so a write to L17's slot would change
the learned A/F trim: do not experiment with writes.

## A02.3 Reading common pairs

| Compare | Tells you |
|---|---|
| L01 vs the active Requested Torque map at logged rpm and J33 | Whether a torque cap is holding (Maximum Torque, VDC) |
| L01 vs L02 | Whether a rev or overboost cut is acting on the throttle |
| L11 vs L12 | Boost tracking; how close you are to the overboost margin (C09) |
| L13 vs L14 | How much of the duty is feedback rather than Wastegate Duty Initial |
| L03 vs J04 | Which side of the timing min() fires: J04 ≈ L03 + L04 − retards means Base Timing; J04 well below L03 means the Primary Ignition + KCA + FLKC side (C07) |
| L04 over time | Flat after a knock event inside the window = the 100-event hold, not continuing knock (C07) |
| L10 vs L09 | Whether the high-pressure pump keeps up (C03) |


| L16 + J28 by MAF voltage (J06) | MAF scaling error (C04) |
