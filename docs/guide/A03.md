# A03. Injector and rail pressure details

Numbers behind C03. LF75404S unless noted; untested on a car.

## A03.1 Injector Scaling arithmetic

* The definition shows **Injector Scaling** as a reference flow: flow [g/s at 0.3 MPa] = 7,610.3 / raw. Stock raw
  2,918 = 2.61 g/s. Higher displayed flow = lower raw = less pulse per gram.
* Base pulse [µs at 0.3 MPa] = 131.40 × raw × stoichiometric fuel mass per cylinder per cycle [g], before trims.
* Stock **Injector Flow Compensation (Injectors 1/3)** follows √(0.3 MPa / P): 256 at 0.3 MPa, 44 at 10 MPa, 29 at 24
  MPa. Assumed flow at pressure P = 2.61 × 256 / table(P): 15.2 g/s at 10 MPa. So a 10 MPa rating converts as
  displayed = flow × 44 / 256.
* Only the base quantity and the wall-film step read Injector Scaling; everything downstream is a fraction of base
  fuel (follows) or a time (does not).

*Worked example (inferred arithmetic).* Injectors flowing 30 % more than stock at the same pressure: displayed 2.61 →
3.39 g/s, k = 1 / 1.3 = 0.77. Every table in the C03 rescale list × 0.77; latency and minimum pulse from the injector
data.

## A03.2 Base Fuel Quantity Limit

* **Base Fuel Quantity Limit** (level 3) caps the stoichiometric fuel quantity before anything uses it; enrichment,
  flow compensation and latency come after the cap and do not lift it, so above it the mixture leans as airflow rises
  (inferred from the call order). Stock raw 4,060 in all eight images.
* Shown as g of air per revolution *at stock Injector Scaling*: 4.98 g/rev (about 385 %), out of reach behind the 3.31
  g/rev load clamp.
* In air terms the ceiling scales with the displayed injector flow: ceiling ≈ 4.98 × displayed flow / 2.61 g/rev.
  * Bigger injectors: the ceiling rises; no change needed.
  * E85 by Injector Scaling (about 1.74 g/s): about 3.32 g/rev, just above the load clamp; below about 1.73 g/s it is
    the first limit reached.
  

* To keep the stock ceiling after lowering the displayed flow: new raw = 4,060 × new Injector Scaling raw / 2,918, or
  multiply the displayed value by stock flow / new flow.

## A03.3 Transient Fuel Film Target and Injector Scaling

The film target values are fuel mass (mg) and need no change, but the table is looked up on a fuel-based load that
includes Injector Scaling. After any Injector Scaling change multiply the load axis by new raw / 2,918 (= stock flow /
new flow) to keep the film acting at the same real loads. Stock: 0 up to 0.21 g/rev, 3.5 mg at 1.29 g/rev, the same at
every rpm.

## A03.4 Rail pressure

| Item | Detail |
|---|---|
| Target selection | **Target Rail Pressure** in normal running; **Target Rail Pressure (Pedal Released)** with the pedal fully released; plus **Target Rail Pressure Additive** × **Target Rail Pressure Additive Multiplier** / 255 when no rail sensor fault (zero in stock). **Target Rail Pressure (Combustion Mode 4, Start Delay)** only during a start delay that is 0 in stock. Start targets: C12 |
| Resolution | Table steps 91.5 kPa (13.3 psi); target held while the change is under 0.37 MPa (54 psi); table maximum about 23.3 MPa (3,380 psi) |
| Pump loop | Feed-forward (fuel quantity × rpm) + P (by rpm) + I. The integral holds while the error is inside **HPFP Integral Threshold** (a deadband, stock 0.5 MPa) and steps by **HPFP Integral Step** outside it |
| Pump clamps | Lower **HPFP Command Minimum** (225°); upper **HPFP Command Maximum Base** + **HPFP Command Range** (225 + 120 = 345°). Raising the minimum does not raise the upper limit |
| Solenoid window | **HPFP Solenoid Window End Limit** falls from 333° at 1,600 rpm to 305° from 4,000 rpm at 10 V and above; hardware, leave it |
| P0088 absolute | Actual > **P0088 Rail Pressure High Limit** + 2.5 MPa for 2 s (stock trip 17.5 MPa / 2,540 psi); recovers at ≤ the limit (15.0 MPa). Sets the code and a fail-safe flag; **Throttle Limit (Fuel Pressure Fault)** caps the throttle while the code is pending |
| P0087 / P0088 deviation | Target − actual > 3.3 MPa, or actual − target > 6.0 MPa, for 10 s in normal pump operation |
| P0087 absolute | Actual < **P0087 Rail Pressure Low Limit** − 0.30 MPa (stock 0.40 MPa) for 10 s |
| Sensor | 0.5 V = 0, 7.5 MPa/V, capped at 30 MPa; P0192 below 0.232 V, P0193 above 3.254 V (20.6 MPa); faulted value 0.35 MPa (**Rail Pressure Sensor Fault Value**) |
| Fail-safe rev limit | Deviation faults or a pending P0192/P0193 force **Fail-Safe Rev Limit (Rail Pressure Fault)** (6,100 rpm, full fuel cut; bit mapping inferred). Injector-driver faults use **Fail-Safe Rev Limit (Injector Driver Fault)** and drop the target to **Rail Pressure Fail-Safe Target A** (0.35 MPa) |
