# A04. Sensor inputs and air-measurement details

Numbers behind C04. LF75404S unless noted. Voltages assume a 5 V ADC reference (inferred; every "V" in the definition
rests on it). Every fault limit is on raw voltage and does not move when a scaling changes.

## A04.2 MAP: the two copies

* Engine MAP (VE axis, airflow model, logged MAP) = sample × multiplier + offset, clamped at 256 kPa abs (22.4 psi
  gauge at sea level).
* Boost-control pressure = the same minus 13.3 kPa, clamped the same way, so it reaches 269.3 kPa abs actual (24.4 psi
  gauge). Logging-patch L11/L12 add the 13.3 kPa back.
* The overboost cut compares against this copy with the reference ROM's 33 kPa margin, hence the 236 kPa abs (19.5 psi gauge)
  ceiling on **Overboost Limit**. The Forester tS and LV9N use a 10 kPa margin (C09).
* With stock scaling the engine copy reaches the clamp at 4.44 V and the boost copy at 4.65 V.

## A04.3 MAF: what saturates where

| Value | Saturates at | Used by |
|---|---|---|
| MAF table input | 4.92 V | — |
| Logged / OBD MAF (J05) | 300 g/s | Logging only |
| Modelled cylinder flow | Does not saturate | Base fuel, load, and through load ignition and boost |
| Load | 3.31 g/rev (256 %) | Every load axis |
| Base fuel quantity | **Base Fuel Quantity Limit** (4.98 g/rev at stock **Injector Scaling**) | Base pulse, wall film (A03) |
| Side-function air copy | 218 g/s | Purge, evap monitor, TGV request, an exhaust-temperature filter (axis ends at 210 g/s), torque-model lag rate, rear-O2 heater, catalyst monitor, charging, the CAN full-load air estimate. None matters above 218 g/s (the CAN estimate may read low, inferred) |

## A04.4 MAP sensor arithmetic

Multiplier = (P2 − P1) / (V2 − V1); offset = P1 − multiplier × V1 (kPa abs). The definition shows kPa/V and kPa; the
stored raw values are slope × 5 and offset × 256. Example 0.5 V = 20 kPa, 4.5 V = 300 kPa: 70 kPa/V (raw 350), −15 kPa
(raw −3,840).

## A04.5 Throttle body: tables that must stay consistent

| Table | Role | Must equal |
|---|---|---|
| **Throttle Area from Opening** | Opening % → area (torque model, cranking) | **Throttle Area from Opening (Monitor)** |
| **Throttle Opening (Required Area)** | Area → commanded opening % | Exact inverse of the above; **Throttle Opening (Monitor)** |
| **Throttle Area from Throttle Position (Airflow Model)** | Position → area for the airflow model and MAP substitute | Same mm² as **Throttle Area from Opening** |
| **Throttle Required Area** / **Torque Fraction from Throttle Area** | Torque fraction ↔ area | Inverse pair; cancel at part throttle (C13); leave alone |
