# A08. Cam control details

How a cam target becomes valve duty, and what the level-3/4 tables in AVCS Control & Feedback do. Read from LF75404S;
the 2017/2018 images use the same logic. Decoded from code, untested on a running engine. "Cam 1" and "cam 2" are the
two banks in code order; which physical bank is which was not traced.

## A08.1 How the target is built

```
target = v x [ S_A x w + S_B x (1 - w) ]                                    v = TGV open fraction
       + (1 - v) x [ 3A x w + (3B + Offset 3B x Factor 3) x (1 - w) ]       w = AVCS Barometric Blend
       + Offset A x Factor x w + Offset B x Factor x (1 - w)                 (any TGV state)
S = set 1 (Normal) or set 2 (High Pedal), chosen by the high-pedal latch; result clamped to ±90°
```

* Negative intake cells are not floored for control; they simply hold the cam at rest.
* 2018: the result is then capped by the oil-temperature ceiling tables (90° stock, Low table live at all
  temperatures).
* The code has further alternate target tables, selected by inputs not decoded; they are not in the definition.

## A08.2 Enable

Closed-loop cam control runs only when all of these hold; otherwise the cam is parked at rest on a fixed low duty:

* rpm at or above **Intake AVCS Minimum RPM (Oil Temp)** / **Exhaust AVCS Minimum RPM (Oil Temp)** (100 rpm
  hysteresis) and below 8,600 rpm;
* oil above 14 °F (-10 °C) and above **AVCS Minimum Oil Temp (IAT at Start)**;
* **AVCS Activation Delay After Start** has run out.

When both cams are under control, Primary Ignition and the open-loop fuel tables switch to their "AVCS Active" maps at
once; when control drops out they fade back to "AVCS Inactive" (about 0.3 s for ignition).

Leave alone: **AVCS Activation Delay After Start (Second)** can only shorten a hold that has already ended.
**Intake AVCS Fixed Duty Window After Start** and **Intake AVCS Fixed Duty Minimum Oil Temp (IAT at Start)** appear to
hold the intake valves at 52 % duty after start, but in stock the window ends before cam control starts, so they
probably do nothing.

## A08.3 Feedback

Per cam, every 20 ms:

```
duty = clamp( hold + P + D , 31.9 % .. 81.1 % )
```

* *hold*: the duty at which the valve holds the cam still, about 37-67 %. Its source is not decoded.
* *P* (only when the error is over 0.5°), by rpm and error (target - actual):
  * driving (pedal pressed or above about 4 km/h): **Intake AVCS Feedback Duty (Cam 1)**,
    **Intake AVCS Feedback Duty (Cam 2)**, **Exhaust AVCS Feedback Duty (Cam 1)**,
    **Exhaust AVCS Feedback Duty (Cam 2)**;
  * pedal released at standstill: the "(Idle, Cam n)" versions, e.g. **Intake AVCS Feedback Duty (Idle, Cam 1)**;
  * stock intake idle map at 2,000 rpm: -8 % at -40° error, -4 % at -6°, 0 at 0, +4 % at +6°, +7 % at +40°. The
    driving maps differ only in the outer cells;
  * times an oil factor per sign of error, e.g. **Intake AVCS Feedback Oil Factor (Normal, Positive Error)**: 1.0 to
    212 °F (100 °C), 1.05 from 248 °F (120 °C).
* *D* (damping, only when the error moves fast), by rpm and error rate: **Intake AVCS Rate Feedback Duty (Cam 1)**,
  **Exhaust AVCS Rate Feedback Duty (Cam 1)** and the cam 2 copies. The intake term is multiplied by
  **Intake AVCS Rate Feedback Oil Factor**: 1.0 to 158 °F (70 °C), 0 from 176 °F (80 °C), so intake damping only acts
  with cool oil. Stock intake damping acts only at 700 rpm; exhaust from 1,000 to 5,000 rpm.

## A08.4 Valve output

```
output = duty x coil factor x current adaptation x battery factor
```

| Table | Stock / note |
|---|---|
| **Intake AVCS OCV Battery Voltage Compensation**, **Exhaust AVCS OCV Battery Voltage Compensation** | 1.40 at 10 V, 1.0 at 14 V, 0.875 at 16 V; always used |
| **Intake AVCS OCV Coil Factor (Oil Temp)** then **Intake AVCS OCV Coil Factor (Oil Temp, Settled)** | First moments after power-up, then Settled. Identical in stock; edit both. Intake 0.82 at -40 °F to 1.17 at 284 °F |
| **Exhaust AVCS OCV Coil Factor (Oil Temp)**, **Exhaust AVCS OCV Coil Factor (Oil Temp, Settled)** | Same pairing. 0.66 at -40 °F, 1.0 at 203 °F, 1.11 from 284 °F |
| **Intake AVCS OCV Expected Current**, **Exhaust AVCS OCV Expected Current** | 0.67 A at 50 % duty, 1.12 A from 81 %; the learned correction (0.5-1.5) compares measured current with this |
| **Intake AVCS OCV Adaptation Step (Cam 1)** and the other three | Learning step size; learns while duty is at least 20 % |
| **Intake AVCS OCV Current Integral Step**, **Exhaust AVCS OCV Current Integral Step** | Integral term forced to zero in stock |
| **Intake OCV Base Duty (Cam 1, Legacy Path)** and its three siblings | Older control path, not selected |

## A08.5 When to touch the control tables

Only when J29-J32 do not follow the targets after a hardware change (oil viscosity, cam gears, valves):

| Symptom | Change |
|---|---|
| Steady offset that never closes | P at small errors (the 0.5° deadband stays) |
| Slow approach | More P at large errors |
| Overshoot or oscillation | Less P, or more D; remember intake D is off with hot oil |
| Different behaviour at low battery voltage | The battery compensation |

Change cam 1 and cam 2 together unless the banks really differ, and keep the driving and idle maps equal in their
shared middle cells.
