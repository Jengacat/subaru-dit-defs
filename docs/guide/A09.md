# A09. Limiter values by image

Every value behind the rev limiter, overboost cut, speed limiter and fail-safe rev limit, with user level and stock
value per image, read from the stock ROMs through the definition's scalings. Folder Torque & Throttle > Torque Limits
& Engine Protection unless noted. What each does: C09. Mechanism: C18.

Image columns: *WRX* = LF75404S, LF75300H, LF79002P, LF79100P, LF9C100P (identical for every value here); *Forester* =
LF78001H (CVT); *LV9N1C* = LV9N101C (CVT); *LV9N0F* = LV9N100F (manual).

## A09.1 Rev limiter

| Value | Level | WRX | Forester | LV9N1C | LV9N0F |
|---|---|---|---|---|---|
| **Rev Limit RPM** | 1 | 6,700 | 6,100 | 6,500 | 6,700 |
| **Rev Limit Reset RPM** | 1 | 6,600 | 6,000 | 6,400 | 6,600 |
| **Rev Limit Full Cut RPM** | 1 | 6,700 | 6,100 | 6,500 | 6,700 |
| **Rev Limit Full Cut Reset RPM** | 1 | 6,700 | 6,100 | 6,500 | 6,700 |
| **Rev Limit Stage 1 RPM** | 1 | 6,700 | 6,100 | 6,500 | 6,700 |
| **Rev Limit Stage 2 RPM (Stage 1 Hold)** | 1 | 6,700 | 6,100 | 6,500 | 6,700 |
| **Rev Limit Reset Maximum MAP** | 1 | 168 kPa abs (9.7 psi) | same | same | same |
| **Rev Limit Full Cut Speed Threshold** | 3 | 255 km/h (never) | same | same | same |
| **Rev Limit Full Cut Speed Threshold Hysteresis** | 3 | 0 | same | same | same |

The rpm values are stored in 0.195-rpm steps; the editor rounds an entry to the nearest step. Above
**Rev Limit Full Cut Speed Threshold** the fuel cut would use the Stage 1 / Stage 2 rpm values instead of the Full Cut
pair; stock it can never be reached.

## A09.3 Overboost

| Value | Level | WRX | Forester, LV9N1C, LV9N0F |
|---|---|---|---|
| **Overboost Limit** peak | 1 | 16.0 psi (211 kPa abs) | 16.4 psi on the Forester, 16.0 psi on LV9N |
| **Overboost Margin** | 2 | 3.9 psi (26.7 kPa) | same |
| **Overboost Delay** | 2 | 2.0 s | same |
| **Overboost Flag Reset Margin** | 3 | 0 | same |
| **Overboost Cut Margin (Limit State)** | 3 | 4.8 psi (33 kPa) | *1.5 psi (10 kPa)* |
| **Overboost Cut Hysteresis (Limit State)** | 3 | 2.2 psi (15 kPa) | *2.9 psi (20 kPa)*: the state ends 1.5 psi below the limit |

*Compensation.* **Overboost Limit** is compensated for baro and IAT by the same factor as **Target Boost**, in
absolute terms: effective limit ≈ (table + 13.3 kPa) x factor - 13.3 kPa. The margins add to that.

*Ceiling.* The overboost check reads a pressure that stops at 269.3 kPa abs (24.4 psi):

| Margin | Cut state unreachable above (limit) | Fuel-cut flag unreachable above |
|---|---|---|
| 4.8 psi (33 kPa) | ≈ 236 kPa abs (19.5 psi) | ≈ 243 kPa abs (20.6 psi) |
| 1.5 psi (10 kPa) | ≈ 259 kPa abs (22.9 psi) | ≈ 243 kPa abs (20.6 psi) |

**Overboost Margin** is unsigned: a negative entry wraps to about +250 kPa and the fuel cut can never arm.

## A09.5 Fail-safe rev limit

| Value | Level | WRX, Forester, LV9N1C | LV9N0F |
|---|---|---|---|
| **Fail-Safe Rev Limit (Rail Pressure Fault)** | 2 | 6,100 rpm | max (≈ 12,800 rpm: off) |
| **Fail-Safe Rev Limit (Injector Driver Fault)** | 2 | 6,100 rpm | max (off) |
| **Fail-Safe Rev Limit (Unused Fault Flag)** | 4 | 6,100 rpm, never selected | max |
| **Fail-Safe Rev Limit Hysteresis** | 3 | 100 rpm | 100 rpm |
| **Fail-Safe Rev Limit Minimum Above Idle Target** | 3 | 200 rpm | 200 rpm |

The fault flags behind each limit sit at different bit positions per image; their meaning was checked in LF75404S
only. Rail Pressure Fault: the rail-pressure deviation monitor bits or a pending P0192/P0193 (mapping inferred).
Injector Driver Fault: P062D/P2146. P0088 does *not* select a fail-safe rev limit: it trips at
**P0088 Rail Pressure High Limit** (15.0 MPa / 2,175 psi) plus about 2.5 MPa for about 2 s (about 17.5 MPa / 2,540 psi
stock), recovers at the limit, and while pending caps the throttle through **Throttle Limit (Fuel Pressure Fault)**
(about 18 % at 2,000-4,000 rpm, 6 % from 4,400 rpm). P0087 counts below **P0087 Rail Pressure Low Limit** minus 0.30
MPa (44 psi).

## A09.7 Worked example: 7,000 rpm on a 2015 WRX

| Value | Stock | New |
|---|---|---|
| **Rev Limit RPM** | 6,700 | 7,000 |
| **Rev Limit Full Cut RPM** | 6,700 | 7,000 |
| **Rev Limit Full Cut Reset RPM** | 6,700 | 7,000 (or 6,850 for a longer cut per bounce, inferred) |
| **Rev Limit Stage 1 RPM** | 6,700 | 7,000 |
| **Rev Limit Stage 2 RPM (Stage 1 Hold)** | 6,700 | 7,000 |
| **Rev Limit Reset RPM** | 6,600 | 6,900 |
| **Rev Limit Reset Maximum MAP** | 168 kPa abs | unchanged, or above peak boost to release on rpm alone |
| **FBKC Window RPM Maximum** | 6,400 | 7,000, so knock control keeps working to the limiter |

Before the first pull, check Base Timing, Primary Ignition, open-loop fuel, the cam maps and **Target Boost** between
6,700 and 7,000 rpm.
