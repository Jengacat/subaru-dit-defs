# A10. Drivability details

Reference for C10. Values are LF75404S (2015 WRX, manual) unless noted. A "pass" is one 10 ms task run; an "event" is
one combustion event. Decoded from code, untested on a running engine.

## A10.1 Transient fuel

Two per-cylinder terms, both added to each injection. Each decays only for cylinders injected since the previous pass;
both reset outside the running fuel state.

*Throttle-rate term*

```
increment = (throttle-air rate - neutral) x Throttle-Rate Gain(coolant) x Throttle-Rate RPM Multiplier(rpm) x k
term      = max(Throttle-Rate Term Minimum(coolant), previous + increment)
decay     : injected cylinders keep 25 % of their deviation per pass
```

| Table | Level | Stock |
|---|---|---|
| **Transient Fuel Throttle-Rate Gain** | 2 | 255 to 32 °F (0 °C), 237 at 50 °F, 158 at 68 °F, 103 at 86-140 °F, 90 at 158 °F, 64 from 176 °F (80 °C) |
| **Transient Fuel Throttle-Rate Gain (AT/CVT)** | 2 | AT/CVT codings only; identical |
| **Transient Fuel Throttle-Rate Gain (Off in Stock)** | 5 | Only if a transmission-coding switch changes; identical |
| **Transient Fuel Throttle-Rate RPM Multiplier** | 2 | 0.24 to 1,200 rpm, 0.30 at 1,600, 0.35 at 2,000, 0.40 at 2,400-3,200, 0.45 at 3,600, 0.55 from 4,000 |
| **Transient Fuel Throttle-Rate Term Minimum** | 3 | -998 µs to 140 °F (60 °C), -499 µs from 158 °F (µs at the 0.3 MPa reference) |

The rpm multiplier is inactive for the first second with the pedal released and at steady idle at standstill. LTFT
learning runs only while all four throttle-rate terms are near zero.

*Film term*

```
step = (Film Target(load, rpm) now - last pass) x Injector Scaling x k     (all four cylinders)
film = film + step, decaying about 1.5 % per injection
out  = film x Film Gain RPM Multiplier(rpm), never negative in stock
```

| Table | Level | Stock |
|---|---|---|
| **Transient Fuel Film Target** | 2 | 0 mg up to 0.21 g/rev, 0.30 at 0.39, 0.65 at 0.51, 1.05 at 0.64, 1.50 at 0.77, 2.59 at 1.03, 3.53 at 1.29 g/rev; same at every rpm |
| **Transient Fuel Film Gain RPM Multiplier** | 3 | 1.0 to 2,000 rpm, 0.69 from 5,200 rpm |

* A rise from 0.39 to 1.03 g/rev adds roughly 870 µs (at the 0.3 MPa reference) to each following injection, fading
  about 1.5 % per injection.
* No step while the throttle-air rate is near neutral, in the first second with the pedal released, or at steady idle.
* The values are fuel mass, but the load axis is fuel-based and scales with **Injector Scaling**: after an injector
  change multiply the axis by new raw / 2918.

**Transient Fuel Injected-Cylinder Mask (Event Index 0)** to Index 3 (level 4) encode the 1-3-2-4 order. Don't edit.

*Event enrichments* (largest wins). Standstill tip-in arms below 5 km/h at least 200 passes after the last event,
fires as the pedal leaves zero (hold 200 passes cold, 60-150 mid) and blocks LTFT learning. Fuel cut recovery
enrichment acts only while the A/F sensor reads slightly lean and no open-loop enrichment is active. The Event Fuel
Adder tables (level 4) start at zero; the Tip-In Extra Pulse tables (Off in Stock) never fire.

## A10.2 Tip-in classification and retard

*Classifier.* A tip-in code is active while the pedal is off zero and the throttle has risen about 3.4 % or more over
the last 40 ms:

| Class | Condition |
|---|---|
| 4 | Throttle was below **Tip-In Retard Class 4 Start Throttle Maximum** and is now at or above **Tip-In Retard Class 4 Throttle Minimum**, with a large enough rise |
| 3 | Peak rise above a larger step |
| 2 | Peak rise above a smaller step |
| 1 | Any other tip-in |

**Tip-In Retard Class Hold Throttle** holds the class once the pedal has been pressed a short while; the code clears
when the throttle closes.

| Table | Level | Stock |
|---|---|---|
| **Tip-In Retard Class 4 Start Throttle Maximum** | 4 | 5.1 % at idle to 30 % from 5,600 rpm |
| **Tip-In Retard Class 4 Throttle Minimum** | 4 | 20.4 % at idle, 44-65 % at 1,600-4,000 rpm, 94 % from 4,800 rpm |
| **Tip-In Retard Class Hold Throttle** | 4 | 13 % at 0 rpm to 38 % from 4,000 rpm |

*Retard.* Fixed per class (calibration, not a table): 0 / 0 / 10° / 10° for classes 1-4 in both speed bands, plus
**Tip-In Timing Retard Temperature Adder** (stock 0). Start and End (C10) are looked up by rpm when the code appears
and counted in passes; Decay is per event. Window: running, pedal pressed, 3,900-6,375 rpm, warm. The retard comes off
after the timing limit and before its rate limit (A07): it shows in J04, not L03.

## A10.3 Surge damping

*Trigger.* Every pass the change of **Surge Damping Throttle Flow Map** (throttle x rpm) is watched. When it stays
above about 0.4 % per 20 ms (manual) for longer than a per-gear, per-rpm-band count (calibration constants), surge
damping triggers; it drops out after 90 active passes. The largest flow change since the trigger is held as the curve
input.

*Swing counter.* Counts rpm swings 0-8 after the trigger, each with a time limit (100 / 20 / 100 / 10 / 100 / 5 / 100
/ 100 / 100 passes); overrunning one ends the term.

```
retard = Curve(gear)(peak flow change) x Phase Factor(gear, rpm band)(swing count)
         x Coolant Factor(coolant) x Combustion Mode Factor(mode) x k   (k = 254/255, or 128/255 in one condition)
```

| Table | Level | Stock |
|---|---|---|
| **Surge Damping Timing Curve (Gear 1)** | 3 | -25° at 0-12.5 % flow change, -20° above |
| **Surge Damping Timing Curve (Gear 2)** to Gear 5 | 3 | -20° at 0-12.5 %, -10° at 25 %, 0 from 37.5 %; Gear 6 all 0 |
| **Surge Damping Timing Phase Factor (Gear 1, Below 1800 RPM)** | 3 | 0 / 0.5 / 0 / 0.3 / 0 / 0.25 / 0 for counts 0-6; other gears 1-5 non-zero only at 1, 3, 5; gear 6 all 0 |
| **Surge Damping Throttle Flow Map** | 4 | 0 at closed throttle, full by 28-37 % throttle |

Coolant and combustion-mode factors: C10. The (AT/CVT Gear 1 … 6) curves, phase factors and
**Surge Damping Timing Coolant Factor (AT/CVT)** are used only on AT/CVT codings.

## A10.4 Lift-off

**Tip-Out Timing Retard** (level 3, gear x MAP). Trigger: pedal released, rpm rising faster than a threshold, rpm ≤
6,600, coolant ≥ 158 °F (70 °C), speed ≥ 10 km/h, plus two flags not identified; only within 1 s of the release.
Latched on the rising edge, held while the trigger stays, removed at once when it clears.

| Gear | 4.4 psia | 5.1 | 6.5 | 8.7 | 10.9 | 13.1 | 15.2 | 17.4 psia and up |
|---|---|---|---|---|---|---|---|---|
| 1 | 0 | 0 | 2 | 11.5 | 15 | 19 | 30 | 30 |
| 2 | 0 | 0 | 2 | 11.5 | 16 | 19 | 21 | 24-30 |
| 3 | 0 | 7 | 14 | 20 | 23 | 25 | 28 | 30 |
| 4 | 0 | 7 | 17 | 20 | 22 | 23 | 25 | 26-30 |
| 5 / 6 | 0 | 10 | 15 | 19 | 22 | 23 | 25 | 26-30 |

**Timing Request Recovery Rate After Tip-Out** (level 3): 0.5° per step to 1,500 rpm, 1° at 2,000, 2° at 2,500, 5° at
3,000, unlimited from 3,500 rpm. With the pedal released the timing request is the live side of the timing limit in
stock, so this shapes fired coast timing (A07).

**Minimum Idle Air (Moving in Gear)** (level 3, rpm x coolant): floor on idle air while moving (≥ 4 km/h) out of
neutral. Stock (base-air units) 2,816 at 400-800 rpm, 3,328 at 1,200 (2,944 hot), 4,608 at 1,600 (3,840 hot), 5,632 at
2,000, 8,192 at 2,800, 13,184 at 4,000, 20,480 at 5,600, 22,016 from 6,400 rpm. The floor may rise 1,536 and fall 831
units per pass; with the pedal pressed and for 0.3 s after release it is at least 7,127.

## A10.5 Decel fuel cut

*Resume rpm* (25 rpm steps):

```
resume = max(fixed floor, idle target + Resume RPM Adder (Coolant)
                          + Resume RPM Adder (Low Speed) [below 15 km/h] + A/C and other calibration terms)
```

*Arming.* Pedal released, at least 6 s since start, no inhibit, rpm ≥ resume + offset: +200 rpm normally; after rpm
has fallen below resume with the pedal still up, +1,300 rpm for 3 s, then +800 rpm until the pedal is pressed. The cut
holds down to the resume rpm.

*Staging.* After **Decel Fuel Cut Delay** the cut is active. A pass counter runs from the start of the condition; the
stage is the number of boundaries passed in the selected row. Gear, rpm band and A/C state are latched at the start.

| Table | Level | Axes | Stock |
|---|---|---|---|
| **Decel Fuel Cut Delay** | 2 | coolant x rpm | 0 below 68 °F (20 °C) or 1,500 rpm, else 0.05 s |
| **Decel Fuel Cut Resume RPM Adder (Coolant)** | 2 | coolant | 1,150 to 14 °F, 1,050 at 32 °F, 1,000 at 50 °F, 400 at 68 °F, 300 from 86 °F |
| **Decel Fuel Cut Resume RPM Adder (Low Speed)** | 2 | coolant | 900 flat |
| **Decel Fuel Cut Staging Time (Gear 1, A/C Off)** … (Gear 6, A/C On) | 2 | rpm band x cylinders cut | Gear 1 slowest (0.2-0.8 s first cylinder, 1.5-1.9 s all four) |
| **Decel Fuel Cut Staging Time (Neutral)** | 2 | speed | 0.10 s, all four at once |

Rpm bands: 1 < 1,800, 2 < 2,800, 3 < 3,800, 4 < 4,800, 5 < 5,800, 6 ≥ 5,800 rpm. Gear 1 also covers gear 0; gear 6
covers higher codes.

*Resume timing*

|---|---|---|---|

## A10.8 Brake override

Brake detection uses brake pressure from the VDC unit over CAN when valid, otherwise the brake switch plus
**Brake Override Deceleration Threshold (No Pressure Signal)**. **Brake Override Delay** by pedal: 2.0 s at 11 %,
1.25-1.5 s at 23 %, 0.75-1.0 s at 40 %, 0.5 s from 60 %. Ramp-down 14-18 % pedal/s to a 1-3 % floor; recovery 50-100
%/s over 0.3-0.5 s. The Brake Booster Vacuum Model tables are Off in Stock.
