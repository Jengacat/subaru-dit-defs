# A12. Start and catalyst-heating tables

Every table of the start / catalyst-heating sequence (C12), by phase, with its user level. Stock values LF75404S. Fuel
mode is the per-injector mode: combustion mode 0 → fuel mode 0, modes 1 and 3 → fuel mode 2, mode 2 → fuel mode 3,
mode 4 → fuel mode 1. Angles are degrees BTDC of compression TDC (zero point inferred).
