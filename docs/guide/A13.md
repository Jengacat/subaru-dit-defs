# A13. Torque and throttle model tables

Per-table reference for folder Torque & Throttle: Requested Torque (4.1), the normal-driving torque limits (4.2), the
throttle model (4.3) and the torque model (4.4). Stock values LF75404S; levels are the definition's user levels (1
Beginner … 5 Debug). The rev limiter, overboost and speed limiter tables of 4.2 are in A09 and A18.

## A13.1 Units

| Quantity | Shown as | Notes |
|---|---|---|
| Torque | ft-lb (Nm alternate) | Stored with an offset, so 0 is not raw 0; range about −148 to +457 ft-lb |
| Torque step | ft-lb per 10 ms | Rise / fall shaping tables |
| Pedal | % | 100 % = full travel per **Accelerator Pedal Span** |
| Opening | % throttle | 100 % = wide open |
| Opening-table column | % of reference torque | target torque ÷ **Throttle Opening Map Reference Torque** |
| Area | mm² effective opening | about 2,150 mm² wide open |

## A13.5 Torque model (4.4)

| Table | Level | Stock | Notes |
|---|---|---|---|
| **Full-Load Reference Brake Torque** (+ Monitor) | 3 | 119-223 ft-lb | Baro-scaled brake part of the full-load reference |
| **Full-Load Reference Torque Loss** (+ Monitor) | 4 | 13-58 ft-lb | Loss part, about the loss table at full boost |
| **Friction and Pumping Torque Loss** (+ Monitor) | 4 | 12-85 ft-lb by rpm × MAP | Added to every request in the throttle model |
| **Full-Load Reference Torque IAT Factor** | 4 | 1.0 flat | Only baro corrects the reference in stock |
| **Air Quantity for Torque** | 4 | torque axis to 277 ft-lb | Only its shape matters; extend the axis if request + losses exceed it |
| Air-path lag and torque response filter tables | 4 | | How fast modelled air and the torque estimate follow; leave alone |
| **Ignition Efficiency vs Retard** | 4 | 0.96 at 8° retard, 0.79 at 20°, 0.48 at 32° | Shares data with two other entries; keep Torque Reduction Spark Retard its exact inverse |
| **Torque Reduction Spark Retard** (folder 2.5) | 3 | 0° at 100 %, 60° at 12.6 % | Efficiency back to retard from base timing; with no cap it lands fired timing on the request (C13.5). Not used in the rev/overboost states |
| Primary Ignition tables (TGV / AVCS variants) | | | Request side of the timing min() rule, effectively WOT timing at high load in stock (C07) |
| Spark Air Compensation Limiter tables | 4 | | Limit on extra air for retarded spark, more when cold. On 2017+ images the "(Alt)" tables are the live ones |
| Torque Model Filter Multiplier tables | 4 | mostly 1.0 | Smoothing after a combustion-mode change |
| **Cylinder Cut Torque Ratio (1 Cylinder)** … **Cylinder Cut Torque Ratio (4 Cylinders)** (folder 4.2) | 4 | 75 / 50 / 25 / 3.9 % | Cap ÷ delivered torque → cylinders cut; also the decel cut stages. **Cylinder Cut Torque Ratio Hysteresis** 0 |

*Rule from the arithmetic.* If you raise Full-Load Reference Brake Torque, raise Throttle Opening Map Reference Torque
with it (from 2,000 rpm) to keep the wide-open point and the excess-torque onset together, and keep Full-Load
Reference Torque Loss near the loss table at full boost. Raising the opening reference rescales every part-throttle
column (C05).

## A13.6 Logging the model

Not on the stock SSM list; the logging-patched ROM adds (C02):

| ID | Name | Meaning |
|---|---|---|
| L01 | Target Torque | Column input of Target Boost and the duty tables |
| L02 | Throttle Torque Request | Brake torque the throttle aims at, after the round trip and the cut caps |
| L18 | Throttle Model Air Requirement | Fraction of full-load torque × spark compensation (inferred) |
| L19 | Torque Model Throttle Opening | Output of the opening tables, before idle air |
| L20 | Throttle Required Area | Area before conversion to opening |
| L21 | ETC Target | After start add and fault caps |

Stock: commanded throttle J11, actual throttle J15, pedal J33, ETC motor drive J34 (meaning inferred).
