# A14. Boost control tables

Per-table reference for folder Boost Control, plus the overboost tables of folder 4.2. Stock LF75404S (the 2016 image
is identical). Boost in psi gauge against 101.3 kPa, with kPa abs where the ECU works in absolute.

## A14.1 Arithmetic (every 20 ms)

```
f        = Target Boost Baro Compensation(rpm, baro) x Target Boost IAT Compensation(IAT)     (x 1.0 low-speed factor)
target   = Target Boost(rpm, TT)_abs x f                       TT = target torque
blimit   = Boost Limit(rpm)_abs x f        -> torque model full-load MAP
oblimit  = Overboost Limit(rpm)_abs x f    -> overboost flag and cut
error    = target - measured               (positive = under target)

comp     = Wastegate Duty Baro Compensation(rpm, baro) x Wastegate Duty IAT Compensation(IAT)
max      = Wastegate Duty Maximum(rpm, TT) x comp
P        = Boost Proportional(error) x Boost Proportional IAT Gain(IAT)               (feedback active only)
I       += Boost Integral Step (Positive Error)(error) x Boost Integral Positive IAT Gain(IAT)
             if error >= Boost Integral Positive Error Deadband and duty < max;   I <= Boost Integral Maximum
I       += Boost Integral Step (Negative Error)(error) x Boost Integral Negative IAT Gain(IAT)
             if error < 0 and duty >= 5 %;                                       I >= Boost Integral Minimum
duty     = min( Wastegate Duty Initial(rpm, TT) x comp + P + I , max )
```

Feedback active = gauge target above **Boost Feedback Activation Threshold**(rpm) (1 psi hysteresis), rpm
above **Boost Feedback Minimum RPM**, boost state normal. Otherwise P = 0 and I = 0. The low-speed factor pulls the
target down under a condition not identified; its floor is 1.0 in stock, so it never acts, and its cals are not in the
definition. A switch that replaces the target with a fixed value is off in stock and not defined either.

## A14.2 Tables

| Table | Level | Axes | Stock | Notes |
|---|---|---|---|---|
| **Target Boost** | 1 | rpm (800-7,600) × target torque (0-310 ft-lb) | Peak 15.9 psi (211 kPa abs) at 5,200 rpm; 9.7 psi from 6,400 rpm; vacuum at 0 ft-lb | rpm axis shared with Boost Limit |
| **Boost Limit** | 1 | rpm | 0.4 psi at 800 rpm, 12.9 at 2,000, 15.2 at 3,200, 16.0 at 5,200, 9.6 from 6,600 | Torque-model full-load MAP, not a cap; raise with Target Boost |
| **Wastegate Duty Initial** | 1 | rpm (2,000-8,000) × target torque (148-295 ft-lb) | 0 % below about 175-220 ft-lb at most rpm; 30-53 % at 258 ft-lb | Axes shared with Maximum |
| **Wastegate Duty Maximum** | 1 | same | Initial + about 10 % (10 % floor) | Also stops the integral |
| **Target Boost IAT Compensation** | 1 | IAT | 0.78 at −40 °F, 1.05 near 104 °F, 0.96 from 140 °F | Also scales Boost Limit and Overboost Limit |
| **Target Boost Baro Compensation** | 1 | rpm × baro | 1.0 near sea level; down to 0.6 at low baro, 4,000-6,000 rpm | Same |
| **Wastegate Duty IAT Compensation** | 2 | IAT | 0 to 14 °F, 0.58 at 32 °F, 0.8 at 50, 0.9 at 68, 1.1 at 86, 1.31 from 104 °F | Scales Initial and Maximum |
| **Wastegate Duty Baro Compensation** | 2 | rpm × baro | 1.0 near sea level; about 0.5 at 9.3 psia, 5,200-6,100 rpm | Scales Initial and Maximum |
| **Boost Proportional** | 2 | error | −7.5 % at −3.9 psi, −2 % at −1.9, 0 at 0, +1.5 % at +1.6, +4 % at +3.0 psi | |
| **Boost Integral Step (Positive Error)** | 2 | error | 0 up to 0.7 psi; about 0.1 %/20 ms at 1.6-3 psi; 0.2 % at 3.9-4.6 psi | |
| **Boost Integral Step (Negative Error)** | 2 | error | Mirror, down to −0.2 %/20 ms | |
| **Boost Proportional IAT Gain**, **Boost Integral Positive IAT Gain**, **Boost Integral Negative IAT Gain** | 3 | IAT | 0 to 14 °F, 1.31 from 104 °F | No feedback with very cold air |
| **Boost Integral Maximum** / **Boost Integral Minimum** | 3 | | +10 % / −90 % | |
| **Boost Integral Positive Error Deadband** | 3 | | 0.1 psi (0.66 kPa) | |
| **Boost Feedback Activation Threshold** | 3 | rpm | −1.0 psi below 2,800 rpm, 4.1 psi from 2,800 | Gauge against baro; no feedback at a vacuum target |
| **Boost Feedback Minimum RPM** | 3 | | 1,000 rpm | |

## A14.3 Overboost (folder 4.2; C09, C18)

| Table | Level | Stock |
|---|---|---|
| **Overboost Limit** | 1 | Equals Boost Limit from 2,000 rpm (12.3 psi at 1,600 rpm, 3.3 psi at 800) |
| **Overboost Margin** | 2 | 3.9 psi (26.7 kPa); unsigned, a "negative" value acts as about +250 kPa |
| **Overboost Delay** | 2 | 2.0 s |
| **Overboost Flag Reset Margin** | 3 | 0 |
| **Overboost Cut Margin (Limit State)** | 3 | 4.8 psi (33 kPa); 1.5 psi (10 kPa) on LF78001H and LV9N |
| **Overboost Cut Hysteresis (Limit State)** | 3 | 2.2 psi (15 kPa); 2.9 psi (20 kPa) on LF78001H and LV9N |

The pressure the overboost logic sees stops at 269.3 kPa abs, so on the WRX an Overboost Limit above about 236 kPa abs
(19.5 psi) can never trigger the cut (A18).

## A14.4 Logging

| ID | Name | Conversion |
|---|---|---|
| L11 | Target Boost | kPa abs = (x + 3404) / 256 |
| L12 | Boost Control Pressure | same |
| L13 | Wastegate Duty (Full Resolution) | % = x / 256 |
| L14 | Wastegate Duty Feedback | signed, % = x / 256 (inferred) |

J10 (stock) is the 8-bit wastegate duty. The patched parameters are untested on hardware (C02).
