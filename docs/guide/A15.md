# A15. Fueling chain arithmetic

For checking a log against the code, and for rescaling after an injector change. Read from LF75404S; roles as in C15.
Pulse quantities are 0.8 µs timer counts inside the code; the definition shows µs.

## A15.1 Air and load

* Load (g/rev) = cylinder air flow / rpm, clamped at 3.31 g/rev (256 %; 100 % = 1.293 g/rev = 2.0 L of air at standard
  density).
* The saturating side copy of the air flow stops at 218.45 g/s (C15.2).

## A15.2 Base fuel

```
Q     = cylinder air x Injector Scaling / 14.7 / rpm      (per cylinder per cycle, at the 0.3 MPa reference)
Q     = min(Q, Base Fuel Quantity Limit)                  stock limit 4060 raw ~ 4.98 g/rev of air
base  = 16 x Q x [ (1 + STFT - purge) x (1 + LTFT) + extra ]   (simplified; 1.0 at nominal)
```

* STFT: the short-term term carrying the closed-loop correction. LTFT: long-term trim (0.39 %/count, 128 = 0 %).
  Purge: filtered purge rate × learned vapour concentration. Extra: an additive term, neutral in stock.
* *Rescale after an injector change*: Base Fuel Quantity Limit new = 4060 × new raw Injector Scaling / 2918, and
  the **Transient Fuel Film Target** load axis × new raw / 2918 (2918 = stock raw Injector Scaling).

## A15.3 Fuel factor (normal running)

```
F  = Fuel Factor Correction + small trims + TGV transition fuel + E          (256 = x1.0)
E  = max( min( max(OL + Additional, Floor), 256 ),                          (capped at lambda 0.5)
          warm-up + running after-start + one start term,
          standstill tip-in,
          fuel-cut recovery term (probably) )
OL = max( Primary Open Loop Fueling [+ DAM additive - subtractive], TGV/AVCS group [same] )
Floor = Open Loop Fueling Floor (Outside Closed Loop) + Low-DAM Enrichment     (out of closed loop only)
quantity = base x F / 256
```

OL contributes only in combustion mode 4 (and 0). Start path (fuel modes 0 and 3): quantity = base × ((after-start +
Fuel Factor Correction + start enrichment) / 256 + 0.5), then a per-fuel-mode multiplier (neutral in stock).

Commanded λ as reported = 256 / (256 + warm-up + primary open loop + additional). Floor, after-start, tip-in and
fuel-cut terms are not included, so the reported λ can be leaner than what is commanded.

## A15.4 Per cylinder and pulse

```
q_n   = max( quantity x Per-Injector Fuel Trim n / 128 + transient_n , cranking pulse )
pulse = max( Injector Latency(P) + q_n x Injector Flow Compensation(P) / 256 , Injector Minimum Pulse Width(P) )
        at most 1 s; single injection in normal running in stock (double / triple windows at 65535);
        the cold-start split of combustion modes 1 and 3 is separate (C12)
```

## A15.5 Transient fuel (10 ms)

* *Film*: each pass, d = Film Target(now) − Film Target(last pass) at fuel-based load and rpm; the step d (converted
  with Injector Scaling and the film coolant gain) is added to all four film terms. Each term decays only for
  cylinders that injected since the last pass (about 98.5 % kept), then × **Transient Fuel Film Gain RPM Multiplier**.
  Negative side floored at zero in stock. Example: 0.39 → 1.03 g/rev step adds about 870 µs (reference) to each
  following injection at first.
* *Throttle rate*: (change in throttle-area air estimate) × **Transient Fuel Throttle-Rate Gain**
  × **Transient Fuel Throttle-Rate RPM Multiplier**, per cylinder, limited below
  by **Transient Fuel Throttle-Rate Term Minimum**, 25 % kept per pass for cylinders that injected. In µs: rescale by
  stock / new flow after an injector change.
* *Off*: first second with the pedal released, steady idle at standstill, and inside a small throttle-rate dead band.

## A15.6 Task rates

Air model every combustion event; transient fuel 10 ms; closed loop 20 ms; purge 20 / 80 ms.
