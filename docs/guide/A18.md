# A18. Limit state and cut details

The exact comparisons behind C18. Read from LF75404S; the same logic and layout in every image (stock values per
image: A09). Torques are above the friction/pumping loss level (**Friction and Pumping Torque Loss**). The table
descriptions call the rev/overboost state 0x0B and the speed-limit state 0x0C.

## A18.1 The latches

| Latch | Sets | Releases |
|---|---|---|
| Rev | rpm > **Rev Limit RPM** | rpm ≤ **Rev Limit Reset RPM** and MAP < **Rev Limit Reset Maximum MAP** |
| Full cut (inside rev state) | rpm ≥ **Rev Limit Full Cut RPM** | rpm ≤ **Rev Limit Full Cut Reset RPM** and MAP < Rev Limit Reset Maximum MAP |
| Full cut above **Rev Limit Full Cut Speed Threshold** | rpm ≥ **Rev Limit Stage 1 RPM** | rpm ≤ **Rev Limit Stage 2 RPM (Stage 1 Hold)** (never in stock: 255 km/h) |
| Overboost | pressure ≥ compensated **Overboost Limit** + **Overboost Cut Margin (Limit State)** | pressure below that − **Overboost Cut Hysteresis (Limit State)** |
| Overboost flag | pressure ≥ compensated limit + **Overboost Margin** for **Overboost Delay** without a break | pressure ≤ compensated limit + **Overboost Flag Reset Margin** |
| Speed | speed ≥ **Vehicle Speed Limit** − **Vehicle Speed Limit Offset** and rpm ≥ **Vehicle Speed Limit Minimum RPM** | condition false and MAP ≤ **Vehicle Speed Limit Reset Maximum MAP** |
| Speed full cut | speed ≥ **Vehicle Speed Limit Full Cut Speed** | speed below it by **Vehicle Speed Limit Full Cut Speed Hysteresis**; held while MAP is above the reset MAP |
| Fail-safe | rpm ≥ max(lowest active Fail-Safe Rev Limit, idle target + **Fail-Safe Rev Limit Minimum Above Idle Target**) | rpm below that by **Fail-Safe Rev Limit Hysteresis** |

Active fail-safe limits: rail pressure (deviation monitor bits or pending P0192/P0193, mapping inferred) and injector
driver fault. A pending P0088 gives **Throttle Limit (Fuel Pressure Fault)**, not a fail-safe rev limit.

"Pressure" and "MAP" here are the boost-control pressure (L12), which stops at 269.3 kPa abs. The compensated
overboost limit is (table + 13.3 kPa) × the Target Boost baro/IAT factor − 13 kPa.

## A18.2 Caps per state

| State | Cap |
|---|---|
| Rev / overboost, with full-cut latch or overboost flag | 0 (all torque removed) |
| Rev / overboost otherwise | no reduction (throttle cap only) |
| Speed limit, full cut active | 0 |
| Speed limit otherwise | no reduction |
| Decel cut, stage n = 1-4 | f × gross torque − losses, f = 191/256, 127/256, 63/256, 9/256 |
| Decel cut, stage 0 | no reduction |
| Idle | idle torque feedback |

## A18.3 Ratio and cut count

* r = 256 × capped torque / unreduced torque on the previous pass, both above the loss level, clamped 0-255.
* Used in the decel, rev/overboost and speed-limit states and some undecoded states.
* Count = 0 if r ≥ 192 (75 %), 1 if ≥ 128 (50 %), 2 if ≥ 64 (25 %), 3 if ≥ 10 (3.9 %), else
  4; **Cylinder Cut Torque Ratio Hysteresis** 0.
* Forced to 4 by the fail-safe rev limit, an internal status value and a stop request. Injector-driver faults can flag
  a single cylinder on their own.

## A18.4 Per-event decision

For each event: n = 1 + cuts among the last three decisions; w = 2500, 100, 50 or 33 for n = 1-4 (code constants);
threshold = 200 if the last decision was a cut and the count is 2, else 100; cut if w × count > threshold. That gives
1 in 4, 1 in 2, 3 in 4 or every event. A flagged cylinder gets zero fuel time and no injection angle, so the injector
is never armed (the 450-600 µs latency / minimum pulse is not fired either).

## A18.5 Spark

* Normal: spark = base timing − **Torque Reduction Spark Retard**(e) − tip-in retard (+ a per-cylinder trim, off in
  stock), capped. e = **Ignition Efficiency vs Retard**(base − timing request incl. KCA and FLKC) × torque-cap ratio.
  With the pedal pressed and no cut, e is floored at 102/256 (about 40 %), so the pull stops at about 34°. Exact
  inverses, so with ratio 1.0 the result is the request wherever it is below base (C13.5).
* Rev/overboost and speed-limit states (under **Limit-State Spark: Normal Target in Rev/Overboost Cut**
  / **Limit-State Spark: Normal Target in Speed Limit**, both set), two undecoded states (bits set, not defined) and
  one more always: normal spark target instead. With the rev/overboost bit cleared a full cut would ask for about 34°
  of retard.
* The coil scheduler never reads the cut count or flags.

## A18.6 Decel fuel cut

| Item | Rule (stock) |
|---|---|
| Resume rpm | idle target + **Decel Fuel Cut Resume RPM Adder (Coolant)** (1,150 rpm cold, 300 rpm from 86 °F / 30 °C) + **Decel Fuel Cut Resume RPM Adder (Low Speed)** (900 rpm below 15 km/h) + other adders (0 on the manual) |
| Cut condition true | pedal released, ≥ 6 s since start, rpm ≥ resume rpm + 200, no inhibit flag |
| Re-entry margin | after dropping below resume rpm: + 1,300 rpm for 3 s, then + 800, instead of + 200 |
| Cut condition false | rpm ≤ resume rpm, or pedal pressed |
| Cut state | condition true for **Decel Fuel Cut Delay** (0 cold or below 1,500 rpm; 0.05 s from 68 °F and 1,500 rpm) |
| Stage latch | at the start of the cut: gear (neutral, 1-6), rpm band (< 1,800 / 2,800 / 3,800 / 4,800 / 5,800 / above), A/C |
| Stage times | **Decel Fuel Cut Staging Time (Gear 1, A/C Off)** and siblings: columns = time to 1, 2, 3, 4 cylinders; neutral uses **Decel Fuel Cut Staging Time (Neutral)** (0.10 s) |
| Cruise hold | cruise active and within 2.5 km/h of target: staging held, up to 18 s |
| After the cut | **Decel Fuel Cut Resume Timing Retard** and the two Decel Fuel Cut Recovery Timing Ramp tables |

With a 700 rpm warm idle the cut starts near 1,200 rpm and ends near 1,000 (computed).

## A18.7 Undecoded states

Three states selected by flags below the speed limiter in priority, one by an internal flag, and one latch on two
inputs with its own pressure release (not the speed limiter, as older notes said). All use a zero or other cap and
normal spark where decoded; their triggers are not decoded.
