# A19. CAN signal reference

The CAN signals a tuner, dash builder or logger builder is likely to use, from LF75404S (2015 WRX 6MT), network
variant 1 (the only one any stock image uses). 500 kbit/s, 11-bit IDs, DLC 8 unless noted. Byte 0 is the first data
byte, bit 7 the most significant. Multi-byte fields are *little-endian*. Torque signals are encoded in Nm on the bus
(1 Nm = 0.738 ft-lb). The full list, including undecoded bits, is in the project's CAN map and DBC.

(read) = arithmetic and source read in code; (inferred) = physical meaning or scale is our interpretation.

The ECU starts sending 190 ms after CAN start with the ignition on, and stops on bus-off, on UDS CommunicationControl
(0x28) and in the programming session. Its own frames carry no checksum; 0x140 byte 1 and 0x361 byte 4 hold rolling
counters.

## A19.3 Confirming the SI-Drive positions

The positions in C19 are inferred from the stock maps. To confirm: log 0x282 byte 5 and 0x141 byte 7 while stepping
through S, S# and I with the engine warm (Intelligent is refused until the engine has warmed past about 126 °F and the
pedal has been lifted). The 0x141 code is the mode in use, and therefore which Requested Torque map is live.

## A19.4 2017 and 2018

Same layouts, except: 0x15A is not received (its mailbox sends a battery-sensor block, 0x6FC); 0x362 is always sent
and gains a 4-bit value in byte 7; 0x361 bytes 5-7 are always 0; the 2018 image decodes five more receive bits.
